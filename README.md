# Digital Design Skills Repository

This repository contains a set of reusable Claude skills, agent instructions, and supporting assets for authoring structured digital design documentation.

## What is included

- Skills for generating and validating design documents using the L0–L3 framework
- Agent guidance for specialized design and documentation workflows
- Templates, grammars, references, and scripts that support the workflow

## Repository structure

- `agents/` — agent-oriented guidance for specific tasks
- `skills/` — reusable skill definitions and supporting assets
- `skills/*/assets/` — templates and grammar files used by the skills
- `skills/*/references/` — framework and syntax documentation
- `skills/*/scripts/` — validation and helper utilities

## Typical use

Use these assets when you want to create or refine:

- design briefs
- solution design concepts
- system design concepts
- element-level design documents

## Getting started

1. Review the relevant skill in `skills/`
2. Open the matching reference files for the document level you are working on
3. Run the provided validation scripts from the repository root when needed

## Notes

This project is intentionally instruction-driven and content-focused. The goal is to make design documentation easier to create, validate, and maintain consistently.
